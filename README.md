# Calius Digital - CMS Public

🌐 **Static CMS untuk Template Marketplace & Blog**

Sistem Content Management System (CMS) berbasis static files untuk mengelola template marketplace dan blog. CMS ini menggunakan teknologi modern dengan fokus pada performa, keamanan, dan kemudahan penggunaan.

- **[UNINSTALL-GUIDE.md](UNINSTALL-GUIDE.md)** - Panduan uninstall/menghapus CMS

## 🚀 Quick Start

### Instalasi
Lihat panduan lengkap di [INSTALL-GUIDE.md](INSTALL-GUIDE.md)

### Uninstall
Jika Anda perlu menghapus CMS ini dari server, ikuti panduan di [UNINSTALL-GUIDE.md](UNINSTALL-GUIDE.md)

## ✨ Fitur Utama

- 🎨 Template Marketplace dengan sistem checkout
- 📝 Blog Management System
- 💳 Payment Gateway Integration (Stripe, PayPal, Midtrans)
- 🔐 Admin Panel dengan 2FA Authentication
- 🌍 Bilingual Support (EN/ID)
- 📱 Responsive Design (Mobile-First)
- ⚡ Performance Optimized
- 🔒 Security Focused
- 🎯 SEO Friendly

## 🛠️ Teknologi

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** PHP (untuk API dan authentication)
- **Database:** JSON files (static)
- **Payment:** Stripe, PayPal, Midtrans
- **Security:** SHA-256 hashing, 2FA, CSRF protection

## 📦 Struktur Folder

```
cms-public/
├── admin/              # Admin panel
├── assets/             # CSS, JS, images
├── data/               # JSON data files
├── scripts/            # Utility scripts
├── tests/              # Test files
├── index.html          # Homepage
├── .htaccess           # Apache configuration
└── README.md           # Dokumentasi ini
```
